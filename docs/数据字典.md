# 数据字典

## 维护说明

- MongoDB 和 Milvus 都不适合直接承载长期字段备注：Mongo 没有稳定的集合/字段注释机制，Milvus 的 schema description 更偏运行时结构说明。
- 本文档作为项目级数据字典，解释 Mongo 集合、Milvus collection 和关键字段含义。
- 后续 schema、字段含义或阶段状态发生变化时，应同步更新本文档。
- 字段状态说明：
  - `已落地`：当前代码或数据库记录中已经使用。
  - `阶段 4 计划`：阶段 4 方案中计划新增或调整，尚未全部落地。
  - `预留`：为后续权限、多租户、管理能力预留。

## Mongo 元数据

Mongo 元数据数据库：`ai_mfg_kb_meta`

当前主要集合：

| 集合 | 状态 | 含义 | 备注 |
|---|---|---|---|
| `datasets` | 已落地 | 知识库容器集合 | 当前默认知识库为设备运维知识库。 |
| `documents` | 已落地 | 文档元数据集合 | 记录上传文件、解析状态、索引状态、用户归属和失败信息。 |
| `tasks` | 已落地 | 导入任务集合 | 记录导入、后续重建等任务进度和失败信息。 |

### datasets

一条记录表示一个知识库容器。

| 字段 | 类型/形态 | 状态 | 含义 | 备注 |
|---|---|---|---|---|
| `_id` | ObjectId | 已落地 | Mongo 内部主键 | 不作为业务关联字段。 |
| `dataset_id` | string | 已落地 | 知识库业务 ID | 当前默认值为 `dataset_default_equipment_ops`。 |
| `name` | string | 已落地 | 知识库名称 | 当前默认名称为“设备运维知识库”。 |
| `description` | string | 已落地 | 知识库说明 | 用于展示和排查。 |
| `created_at` | ISO datetime string | 已落地 | 创建时间 | UTC ISO 字符串。 |
| `updated_at` | ISO datetime string | 已落地 | 更新时间 | 每次默认 dataset 确认时会更新。 |

### documents

一条记录表示一个上传后的文档对象。文档是长期对象，task 是一次执行记录。

| 字段 | 类型/形态 | 状态 | 含义 | 备注 |
|---|---|---|---|---|
| `_id` | ObjectId | 已落地 | Mongo 内部主键 | 不作为业务关联字段。 |
| `document_id` | string | 已落地 | 文档业务 ID | document 的稳定标识，chunk 已关联该字段。 |
| `dataset_id` | string | 已落地 | 所属知识库 ID | 关联 `datasets.dataset_id`。 |
| `owner_user_id` | string | 已落地 | 文档所属用户 | 阶段 3.5 引入，用于导入历史隔离。 |
| `tenant_id` | string | 预留 | 租户 ID | 当前默认 `tenant_default`，后续多租户使用。 |
| `visibility` | string | 预留 | 可见性 | 当前默认 `private`，后续支持 `private/shared/public`。 |
| `latest_task_id` | string | 已落地 | 最新任务 ID | 指向该 document 最近一次导入或重建任务。 |
| `file_name` | string | 已落地 | 原始文件名 | 上传时的文件名。 |
| `file_path` | string | 已落地 | 原始文件本地路径 | 后续重建索引可复用。 |
| `local_dir` | string | 已落地 | 当前导入或重建任务工作目录 | 保存解析产物和中间文件；重建时更新为新 task 的工作目录。 |
| `status` | string | 已落地 | 文档整体状态 | 常见值：`uploaded`、`processing`、`completed`、`failed`、`deleted`。 |
| `parse_status` | string | 已落地 | 解析阶段状态 | 表达文件检查、PDF 转 Markdown、图片增强等解析链路状态。 |
| `index_status` | string | 已落地 | 索引阶段状态 | Milvus 插入成功后写 `completed`；异常由导入失败收口写 `failed`。 |
| `chunk_count` | int | 已落地 | 当前文档切片数量 | 切分时写入预期数量，Milvus 插入成功后按实际入库 chunks 再次确认。 |
| `subject_id` | string | 已落地 | 标准主题 ID | 关联 Milvus 标准主题和 chunk；Milvus 插入成功后随最终索引结果确认。 |
| `standard_subject_name` | string | 已落地 | 标准主题名称 | 用于展示、日志和答案 Prompt；Milvus 插入成功后随最终索引结果确认。 |
| `md_path` | string | 已落地 | 最终 Markdown 路径 | PDF 解析或 Markdown 图片增强后写入。 |
| `file_title` | string | 已落地 | 文件标题 | 通常来自文件名 stem，用于展示和主体识别兜底。 |
| `failed_node` | string | 已落地 | 失败节点 | 记录失败发生在哪个导入节点。 |
| `error_message` | string | 已落地 | 失败信息 | 面向排查的技术错误信息。 |
| `created_at` | ISO datetime string | 已落地 | 创建时间 | UTC ISO 字符串。 |
| `updated_at` | ISO datetime string | 已落地 | 更新时间 | 元数据状态变化时更新。 |
| `index_version` | int | 已落地 | 文档级检索索引产物版本 | 表示该 document 生成到第几版 chunk/vector 入库结果；Milvus 插入成功后随最终索引结果确认，不是 Milvus 物理索引版本或文档内容版本。 |
| `deleted_at` | ISO datetime string | 已落地 | 删除时间 | 文档软删除成功时写入；为空表示未删除。 |
| `image_prefix` | string | 已落地 | 图片对象前缀 | 图片增强有可处理图片时写入 document 维度前缀，例如 `kb-images/{document_id}`；删除 document 时按该精确前缀清理。 |
| `parse_result_zip_path` | string | 已落地 | MinerU 解析结果 zip 路径 | PDF 解析完成后写入本地 zip 路径；Markdown 直接导入时为空。 |
| `parse_result_dir` | string | 已落地 | MinerU 解析结果解压目录 | PDF 解析完成后写入本地解压目录；Markdown 直接导入时为空。 |

### tasks

一条记录表示一次导入或后续重建任务。

| 字段 | 类型/形态 | 状态 | 含义 | 备注 |
|---|---|---|---|---|
| `_id` | ObjectId | 已落地 | Mongo 内部主键 | 不作为业务关联字段。 |
| `task_id` | string | 已落地 | 任务业务 ID | 一次执行的稳定标识。 |
| `document_id` | string | 已落地 | 关联文档 ID | 关联 `documents.document_id`。 |
| `dataset_id` | string | 已落地 | 所属知识库 ID | 关联 `datasets.dataset_id`。 |
| `owner_user_id` | string | 已落地 | 任务所属用户 | 与 document owner 保持一致。 |
| `tenant_id` | string | 预留 | 租户 ID | 当前默认 `tenant_default`。 |
| `task_type` | string | 已落地 | 任务类型 | 支持普通导入 `import` 和重建索引 `rebuild_index`。 |
| `status` | string | 已落地 | 任务状态 | 常见值：`pending`、`processing`、`completed`、`failed`。 |
| `running_nodes` | list[string] | 已落地 | 正在运行的节点列表 | 保存节点原始名称，API 返回时会映射中文展示名。 |
| `done_nodes` | list[string] | 已落地 | 已完成的节点列表 | 保存节点原始名称。 |
| `failed_node` | string | 已落地 | 失败节点 | 导入失败时记录最后运行节点或明确失败节点。 |
| `error_message` | string | 已落地 | 失败信息 | 面向排查的技术错误信息。 |
| `created_at` | ISO datetime string | 已落地 | 创建时间 | UTC ISO 字符串。 |
| `updated_at` | ISO datetime string | 已落地 | 更新时间 | 状态或节点进度变化时更新。 |
| `completed_at` | ISO datetime string | 已落地 | 完成时间 | 任务完成时写入。 |
| `failed_at` | ISO datetime string | 已落地 | 失败时间 | 任务失败时写入。 |
| `task_type=rebuild_index` | enum value | 已落地 | 重建索引任务类型 | 任务类型枚举值，持久记录；运行进度仍由 `status` 表达。 |

## 导入图运行时状态

`ImportGraphState` 是一次导入图执行期间的运行时状态，不是长期存储表。节点只返回 partial state，长期可追踪字段由节点通过 repository 回写到 Mongo `documents`。

### ImportGraphState 解析产物字段

| 字段 | 类型/形态 | 状态 | 写入节点/服务 | 含义 | Mongo 落点 |
|---|---|---|---|---|---|
| `md_path` | string | 已落地 | `node_pdf_to_md` / `node_md_img` | 最终进入切分流程的 Markdown 文件路径。 | `documents.md_path` |
| `md_content` | string | 已落地 | `node_pdf_to_md` / `node_md_img` | Markdown 完整正文内容，后续切分基于该字段或 `md_path` 读取。 | 不长期保存全文 |
| `parse_result_zip_path` | string | 已落地 | `parse_pdf_to_markdown` | MinerU 解析结果 zip 本地路径，仅 PDF 导入时写入。 | `documents.parse_result_zip_path` |
| `parse_result_dir` | string | 已落地 | `parse_pdf_to_markdown` | MinerU 解析结果解压目录，仅 PDF 导入时写入。 | `documents.parse_result_dir` |
| `image_prefix` | string | 已落地 | `enrich_markdown_images` | 当前 document 在 MinIO 中的图片对象前缀，有可处理图片时写入。 | `documents.image_prefix` |

### ImportGraphState chunk 元数据来源字段

这些字段由导入 API 在启动图时写入 state，`index_service` 在 Milvus 入库前统一回填到每个 chunk。

| state 字段 | 类型/形态 | 状态 | Milvus 落点 | 含义 |
|---|---|---|---|---|
| `dataset_id` | string | 已落地 | `CHUNKS_COLLECTION.dataset_id` | 当前导入目标知识库 ID。 |
| `document_id` | string | 已落地 | `CHUNKS_COLLECTION.document_id` | 当前导入 document ID，也是 chunk 幂等删除业务键。 |
| `owner_user_id` | string | 已落地 | `CHUNKS_COLLECTION.owner_user_id` | 当前 document 所属用户 ID。 |
| `tenant_id` | string | 已落地 | `CHUNKS_COLLECTION.tenant_id` | 当前租户 ID；为空时入库默认 `tenant_default`。 |
| `visibility` | string | 已落地 | `CHUNKS_COLLECTION.visibility` | 当前 document 可见性；为空时入库默认 `private`。 |
| `index_version` | int | 已落地 | `CHUNKS_COLLECTION.index_version` | 当前 document 检索索引产物版本。 |
| `file_title` | string | 已落地 | `CHUNKS_COLLECTION.source_title` | 当前来源标题；同时保留 `file_title` 作为展示兼容字段。 |

## Milvus 集合

Milvus collection 实际名称来自环境变量，不在数据字典中硬编码真实 collection 名。

| 配置项 | 状态 | 含义 | 备注 |
|---|---|---|---|
| `STANDARD_SUBJECT_COLLECTION` | 已落地 | 标准主题集合 | 一条标准主题一条记录。 |
| `SUBJECT_ALIAS_COLLECTION` | 已落地 | 标准主题别名集合 | 一条别名一条记录。 |
| `CHUNKS_COLLECTION` | 已落地 | 知识切片集合 | 一条 chunk 一条记录，查询召回主要依赖它。 |

向量字段说明：

- `dense_vector` 是稠密向量字段，用于语义相似度召回。
- `sparse_vector` 是稀疏向量字段，用于型号、报警码、关键词等字面匹配召回。
- 当前物理索引策略为：
  - `dense_vector`：`HNSW`，`metric_type=COSINE`。
  - `sparse_vector`：`SPARSE_INVERTED_INDEX`，`metric_type=IP`。
- 阶段 4 的 `index_version` 表示 document 级检索索引产物版本，不表示上述 Milvus 物理索引版本。

### STANDARD_SUBJECT_COLLECTION

标准主题主表，一条标准主题一条记录，用于管理 `subject_id`、标准名称、别名快照和领域标签。

| 字段 | 类型/形态 | 状态 | 含义 | 备注 |
|---|---|---|---|---|
| `pk` | INT64 auto_id primary key | 已落地 | Milvus 内部主键 | 不参与业务关联。 |
| `subject_id` | VARCHAR | 已落地 | 标准主题稳定业务 ID | chunk 和 alias 都通过该字段关联标准主题。 |
| `standard_subject_name` | VARCHAR | 已落地 | 标准主题名称 | 对外展示、答案 Prompt 和人工排查使用。 |
| `subject_aliases_text` | VARCHAR | 已落地 | 别名快照文本 | 用竖线拼接别名列表，主要用于展示和排查。 |
| `file_title` | VARCHAR | 已落地 | 来源文件标题 | 记录产生或更新该标准主题的文档标题。 |
| `equipment_model` | VARCHAR | 已落地 | 设备型号 | 例如 HAK 180。 |
| `alarm_code` | VARCHAR | 已落地 | 报警码或故障码 | 用于故障排查、维修 SOP、报警说明等场景。 |
| `part_name` | VARCHAR | 已落地 | 部件名称 | 例如急停按钮、传感器、烫金版。 |
| `sop_type` | VARCHAR | 已落地 | SOP 类型 | 例如开机、停机、点检、保养、维修。 |
| `safety_level` | VARCHAR | 已落地 | 安全等级或风险级别 | 用于答案生成时强调安全约束。 |
| `maintenance_stage` | VARCHAR | 已落地 | 维护阶段 | 例如日常点检、故障定位、维修更换。 |
| `dense_vector` | FLOAT_VECTOR | 已落地 | 标准主题文本稠密向量 | 可用于后续导入时匹配已有标准主题。 |
| `sparse_vector` | SPARSE_FLOAT_VECTOR | 已落地 | 标准主题文本稀疏向量 | 用于型号、编号、关键词等字面匹配。 |

### SUBJECT_ALIAS_COLLECTION

标准主题别名索引，一条别名一条记录，用于把用户输入、文件标题或模型识别名映射到标准主题。

| 字段 | 类型/形态 | 状态 | 含义 | 备注 |
|---|---|---|---|---|
| `pk` | INT64 auto_id primary key | 已落地 | Milvus 内部主键 | 不参与业务关联。 |
| `alias` | VARCHAR | 已落地 | 主体别名文本 | 用户可能输入的设备名、型号、简称、文件标题或模型原始识别名。 |
| `alias_type` | VARCHAR | 已落地 | 别名来源类型 | 常见值：`standard`、`file_title`、`llm`、`generated`。 |
| `subject_id` | VARCHAR | 已落地 | 映射到的标准主题 ID | 查询命中别名后，用它过滤 chunk collection。 |
| `standard_subject_name` | VARCHAR | 已落地 | 映射到的标准主题名称 | 用于展示、日志和答案 Prompt。 |
| `file_title` | VARCHAR | 已落地 | 别名来源文件标题 | 当前幂等清理按 `subject_id + file_title` 处理。 |
| `dense_vector` | FLOAT_VECTOR | 已落地 | 别名文本稠密向量 | 查询侧将用户主体提及向量化后检索该字段。 |
| `sparse_vector` | SPARSE_FLOAT_VECTOR | 已落地 | 别名文本稀疏向量 | 用于型号、缩写、编号等字面匹配召回。 |

### CHUNKS_COLLECTION

知识切片集合，一条 chunk 一条记录，存储问答检索用的正文、元数据和混合检索向量。

阶段 4 已将 chunk 从文件标题维度升级到 document 维度。当前不做旧 schema 在线兼容；本地或测试 Milvus 集合如果仍是旧字段结构，可以删除集合后由导入流程重建。

| 字段 | 类型/形态 | 状态 | 含义 | 备注 |
|---|---|---|---|---|
| `chunk_id` | INT64 auto_id primary key | 已落地 | Milvus 自动生成的 chunk 主键 | 用于返回检索命中的切片标识，不作为业务幂等键。 |
| `content` | VARCHAR | 已落地 | 切片正文内容 | 答案生成阶段主要依据该字段组织回答。 |
| `file_title` | VARCHAR | 已落地 | 来源文件标题 | 仅作为展示和兼容字段，不再作为导入幂等删除条件。 |
| `title` | VARCHAR | 已落地 | 当前切片标题 | 通常来自 Markdown 标题。 |
| `parent_title` | VARCHAR | 已落地 | 父级标题 | 保留章节层级，帮助定位切片上下文。 |
| `part` | INT8 | 已落地 | 分片顺序标记 | 表示该 chunk 在章节拆分结果中的顺序。 |
| `subject_id` | VARCHAR | 已落地 | 标准主题 ID | 阶段 2 后查询优先用该字段过滤 chunk。 |
| `standard_subject_name` | VARCHAR | 已落地 | 标准主题名称 | 可读展示字段，检索过滤不依赖该字段。 |
| `equipment_model` | VARCHAR | 已落地 | 设备型号 | 后续可用于同一主题下进一步过滤机型。 |
| `alarm_code` | VARCHAR | 已落地 | 报警码或故障码 | 后续可用于故障排查精确过滤。 |
| `part_name` | VARCHAR | 已落地 | 部件名称 | 后续可用于按部件过滤或聚合。 |
| `sop_type` | VARCHAR | 已落地 | SOP 类型 | 后续可用于区分操作场景。 |
| `safety_level` | VARCHAR | 已落地 | 安全等级或风险级别 | 后续可用于答案安全提示。 |
| `maintenance_stage` | VARCHAR | 已落地 | 维护阶段 | 后续可用于按维护流程过滤。 |
| `dense_vector` | FLOAT_VECTOR | 已落地 | chunk 检索文本稠密向量 | 用于语义相似度召回。 |
| `sparse_vector` | SPARSE_FLOAT_VECTOR | 已落地 | chunk 检索文本稀疏向量 | 用于型号、报警码、关键词等字面匹配召回。 |
| `dataset_id` | VARCHAR | 已落地 | 所属知识库 ID | 入库前由 `ImportGraphState.dataset_id` 回填；阶段 5 查询权限过滤和多知识库过滤使用。 |
| `document_id` | VARCHAR | 已落地 | 所属文档 ID | 入库前由 `ImportGraphState.document_id` 回填；导入幂等、删除、重建索引的核心业务键。 |
| `owner_user_id` | VARCHAR | 已落地 | 所属用户 ID | 入库前由 `ImportGraphState.owner_user_id` 回填；阶段 5 查询私有文档权限过滤使用。 |
| `tenant_id` | VARCHAR | 已落地 | 租户 ID | 入库前由 `ImportGraphState.tenant_id` 回填；为空时默认 `tenant_default`。 |
| `visibility` | VARCHAR | 已落地 | 可见性 | 入库前由 `ImportGraphState.visibility` 回填；为空时默认 `private`。 |
| `index_version` | INT64 | 已落地 | 文档级检索索引产物版本 | 入库前由 `ImportGraphState.index_version` 回填；表示该 document 的 chunk/vector 入库版本。 |
| `chunk_index` | INT64 | 已落地 | document 内 chunk 顺序 | 入库前按最终 chunks 顺序从 `0` 递增。 |
| `enabled` | BOOL | 已落地 | chunk 是否启用 | 当前入库默认 `true`；阶段 6 chunk 启停能力和阶段 5 查询过滤使用。 |
| `source_title` | VARCHAR | 已落地 | 来源标题 | 当前使用 `file_title`，用于引用展示和兼容过渡。 |

## Document 生命周期 API

| 接口/模型 | 状态 | 关键字段 | 含义 |
|---|---|---|---|
| `DELETE /documents/{document_id}` / `DeleteDocumentSchema` | 已落地 | `document_id`、`status`、`deleted_at` | 清理当前用户 document 的 chunk 和图片后执行 Mongo 软删除。 |
| `POST /documents/{document_id}/rebuild` / `RebuildDocumentSchema` | 已落地 | `task_id`、`document_id`、`dataset_id`、`index_version` | 复用原 document 创建 rebuild task，并通过后台任务重新执行导入图。 |
| `GET /documents` | 已落地 | `status` 查询参数 | 默认排除 deleted；显式传 `status=deleted` 可查看当前用户删除历史。 |

删除和重建都要求 `X-User-Id`。document 不存在或 owner 不匹配统一返回 404；deleted 或仍在 uploaded/processing 状态的 document 重建、处理中 document 删除返回 409。

## 关联关系

```text
datasets.dataset_id
  -> documents.dataset_id
  -> tasks.dataset_id
  -> CHUNKS_COLLECTION.dataset_id

documents.document_id
  -> tasks.document_id
  -> CHUNKS_COLLECTION.document_id

STANDARD_SUBJECT_COLLECTION.subject_id
  -> SUBJECT_ALIAS_COLLECTION.subject_id
  -> CHUNKS_COLLECTION.subject_id
```

## 状态枚举

### document/task 状态

| 值 | 含义 | 备注 |
|---|---|---|
| `pending` | 待处理 | task 初始状态，document 的解析/索引子状态也会使用。 |
| `uploaded` | 已上传 | document 上传完成，后台导入任务待处理。 |
| `processing` | 处理中 | 当前正在执行导入链路。 |
| `completed` | 已完成 | 对应阶段处理成功。 |
| `failed` | 已失败 | 对应阶段处理失败，查看 `failed_node` 和 `error_message`。 |
| `deleted` | 已删除 | Mongo document 软删除状态；Milvus chunk 和 MinIO 图片已完成清理。 |

### visibility

| 值 | 状态 | 含义 | 备注 |
|---|---|---|---|
| `private` | 已落地 | 仅 owner 可见 | 当前默认值。 |
| `shared` | 预留 | 指定成员或范围可见 | 阶段 7 以后再定义成员策略。 |
| `public` | 预留 | 公共可见 | Demo 公共知识库可使用。 |

### task_type

| 值 | 状态 | 含义 | 备注 |
|---|---|---|---|
| `import` | 已落地 | 普通上传导入任务 | 当前默认任务类型。 |
| `rebuild_index` | 已落地 | 重建索引任务 | 复用原 document，创建新 task，递增 `index_version`。 |
