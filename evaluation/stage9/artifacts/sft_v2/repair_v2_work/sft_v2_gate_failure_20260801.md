## 停止原因

四类核心门禁仍未闭环，尤其 21 条 `HyDE`（假设文档改写检索）轨迹没有证明绑定目标证据的排名或分数相对首次本地检索真实提升。继续导出会把预设路线当成真实检索结果，因此按方案停止，不以集合变化、模板改写或放宽阈值替代真实提升。

本次执行发生在“失败时持久化 Provider 记录”修复之前，临时目录退出后本轮逐条 Provider 记录未保留；失败 ID 和门禁异常来自进程最终异常，已在本报告固化。生成器现已改为后续执行时先持久化 Provider 记录和逐 case 门禁明细，再决定是否允许输出候选。
